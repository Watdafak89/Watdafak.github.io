# ระบบบันทึกหลังการสอน AI อาชีวศึกษา

เว็บภาษาไทยที่พัฒนาจาก `app.py` ต้นฉบับ เก็บสำรองไว้ที่ `app.original.py`

## เปิดใช้งานบนเครื่องนี้

เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

เข้า http://127.0.0.1:8501 ใช้รหัสผ่านเดิมที่กำหนดไว้ในไฟล์ต้นฉบับ
สามารถกำหนดรหัสผ่านผ่าน environment variable `SYSTEM_PASSCODE` ได้

## วิธีใช้

1. เข้าสู่ระบบ ใส่ Gemini API Key ชื่อครู และสาขาวิชา
2. แนบแบบฟอร์ม Word ที่มีช่องแทนค่า และโครงการสอน (PDF, DOCX, TXT, PNG, JPG)
3. เลือกระดับชั้น ปวช. 18 สัปดาห์ หรือ ปวส. 15 สัปดาห์
4. กำหนดตารางได้ 1–4 คาบต่อสัปดาห์ วันเริ่มต้น และวันงดสอน
5. สร้างร่าง แล้วดาวน์โหลด Word เพื่อตรวจและเติมข้อมูลผลการสอนจริง

วันงดสอนใช้รูปแบบ `8:เหตุผลการงดสอน` หนึ่งรายการต่อบรรทัด
แต่ละสัปดาห์นับรอบ 7 วันเริ่มจากวันเริ่มต้นที่เลือก

## ช่องแทนค่าในแบบฟอร์ม

ใช้ `{{ teacher_name }}` สำหรับชื่อครู ส่วนข้อมูลรายสัปดาห์รองรับทั้ง
`{{ subject }}` และ `{{ w.subject }}`:

`code`, `subject`, `week`, `date`, `date_display`, `time`, `time_display`,
`topic`, `level`, `department`, `check_on`, `check_off`, `off_reason`,
`student_eval`, `teacher_eval`, `problem_solution`

ไฟล์ที่ไม่มีช่องแทนค่าจะได้รับข้อความแจ้งให้แก้แบบฟอร์ม
การรวมเอกสารเก็บรูปและความสัมพันธ์ของไฟล์ด้วย docxcompose โดยใช้ header/footer ของเอกสารแรก
ตรวจการแบ่งหน้าของแบบฟอร์มจริงใน Word อีกครั้ง เพราะขึ้นกับความยาวเนื้อหาและฟอนต์

## การประมวลผล

API Key อยู่ใน session ของผู้ใช้ ไม่บันทึกลงไฟล์ การล็อกระบบล้าง session
โครงการสอนส่งให้ Google Gemini เมื่อกดสร้างร่าง แบบฟอร์ม Word ประมวลผลบนเครื่อง
เลือกโมเดลตาม [เอกสาร Google Gemini](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash)
โดยมี Flash-Lite เป็นตัวสำรอง การใช้จริงขึ้นกับสิทธิ์และโควตาของ API Key
เว็บนี้เปิดเฉพาะเครื่องนี้ ยังไม่ได้เผยแพร่บนอินเทอร์เน็ต

## ตรวจสอบ

```powershell
.\.venv\Scripts\python.exe -m unittest test_app -v
```

ตรวจหน้าเข้าสู่ระบบ การเลือกระดับชั้น การตรวจข้อมูลที่ขาด วันเริ่มสอน และการรวม Word
ยังไม่ได้ทดสอบเรียก AI จริง เนื่องจากไม่ได้รับ API Key และเอกสารโครงการสอน/แบบฟอร์มจริง
